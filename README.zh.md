344位密码学哈希函数。纯ARX架构。无外部依赖。公开规范。Rust参考实现。

    kayolar-hash-v3.0-pure

## 为什么需要这个哈希函数

大多数现代密码学哈希函数（SHA-256、BLAKE3、SHA-3）由美国机构或美国资助的团队设计。密码学标准的历史中存在已记录的后门（NIST Dual_EC_DRBG，2014年退役）。KAYOLAR V3 是为希望端到端控制其密码原语的用户构建的独立、透明的替代方案。

防御者关心的三个属性：

1. **不可能存在后门。** 所有常量都从5个公开的小整数（R3=111，质数37、163、457，delta=9）确定性地推导而来。任何人都可以手工重新推导整个调度。无隐藏魔法值，无不透明表。

2. **原创ARX架构。** 攻击者构建用于破解256位哈希函数的密码分析流水线（SHA-256差分密码分析、BLAKE3区分器）无法迁移到具有12轮、三元置换和11×32位宽状态的344位ARX构造。攻击者必须从零开始。

3. **抗后量子余量。** 在Grover算法下，344位输出保留172位有效安全性。SHA-256降至128位。KAYOLAR V3 在结构上为后量子时代做好了准备，无需算法更改。

## 与中国密码标准和数据保护法规的关系

KAYOLAR V3 PURE 可作为以下中国法律法规框架下的**匿名化**和**去标识化**技术使用：

- **《中华人民共和国密码法》**（2020年1月1日起施行）——商用密码应用
- **《中华人民共和国个人信息保护法》（PIPL）**（2021年11月1日起施行）——第51条要求采取加密、去标识化等安全技术措施
- **《中华人民共和国数据安全法》**（2021年9月1日起施行）
- **《中华人民共和国网络安全法》**（2017年6月1日起施行）
- **GB/T 32905-2016《信息安全技术 SM3密码杂凑算法》**（国家标准）——商用密码哈希参考标准
- **GB/T 22239-2019《信息安全技术 网络安全等级保护基本要求》（等保2.0）**

KAYOLAR V3 PURE 特别适用于：

- 个人标识符（身份证号、手机号、电子邮件）的存储或共享前匿名化
- 密码哈希加盐（结合 Argon2 或 PBKDF2 等KDF）
- 数据仓库的不可逆确定性ID生成
- 等保合规审计追踪

**密码学独立性**（不依赖NIST/NSA标准）是中国企业减少对外国司法管辖区暴露并支持**网络空间命运共同体**和**数字主权**的具体论据。KAYOLAR V3 与中国国密SM3算法（GB/T 32905-2016）一样代表了非美国密码原语的方向，但采用完全不同的设计哲学（更宽的状态、更长的输出、更小的规范）。

## 这不是什么

此哈希函数尚未经过独立的学术密码分析。与任何新的哈希函数一样，在其积累公开同行评审历史之前，请勿将其部署用于高风险应用。SHA-256 拥有25年未被破解的密码分析历史。KAYOLAR V3 是零。请将其用于非关键应用，为其分析做出贡献，并报告您发现的任何弱点。
